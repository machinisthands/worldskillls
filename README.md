# Machinist Hands – WorldSkills CNC Milling Test Projects

A static website for the WorldSkills CNC Milling test projects from 2007 to 2019. Each project has an interactive 3D model, its engineering drawing and downloads.

Live address (GitHub Pages): https://machinisthands.github.io/worldskillls/

## How the site is made

Every page is a real HTML file with its content already in it. This is what search engines need. The pages are **generated**, so you never edit 24 files by hand:

```
templates/layout.html   ← header, footer and <head> (SEO tags) shared by every page
templates/home.html     ← home page content
templates/project.html  ← project page content (one template for all projects)
data/projects.json      ← the list of projects
data/medallists.json    ← CNC Milling medallists per year (shown on project pages)
notes/<project>.md      ← your machining notes for a project (optional)
scripts/build.py        ← makes the pages from the files above
```

After changing a template or the project list, run:

```
python scripts/build.py
```

It rewrites `index.html`, the 23 `worldskills-<year>-test-project-<n>.html` pages, `404.html`, `sitemap.xml` and `robots.txt`. Don't edit those generated files directly, because the next build overwrites them.

## Machining notes

Each project page can have a **Machining Notes** section with your own explanation of the part (setups, tools, sequence, tips). Your own text is what makes the site valuable for visitors, Google and AdSense.

1. Copy `notes/_template.md` to `notes/<project folder>.md`, for example `notes/2019-1.md`.
2. Write in plain text: a blank line starts a new paragraph, `## ` makes a small heading, `- ` a bullet, `1. ` a numbered step, `**text**` bold.
3. Run `python scripts/build.py`.

A project without a notes file has no notes section, so pages never show an empty heading. `notes/2013-2.md` is an example written from the drawing: please check it and rewrite it in your own words.

## Folder layout

The structure follows [HTML5 Boilerplate](https://html5boilerplate.com/) (v9):

```
index.html, worldskills-*.html  ← pages (generated by scripts/build.py)
404.html                 ← "page not found" page (GitHub Pages uses it automatically)
css/style.css            ← all styles (colours at the top; light theme follows the device)
js/app.js                ← small script for every page (footer year, project pickers)
js/viewer.js             ← 3D viewer (project pages only)
js/edges-worker.js       ← finds the edge lines of a model, in the background
js/vendor/               ← three.js bundle, Draco decoder, workshop HDRI (don't edit;
                           the bundle is rebuilt from scripts/three-entry.js, see its first lines)
img/                     ← site images (logo)
fonts/                   ← Inter + Barlow Condensed (self-hosted, OFL licence)
favicon.ico, icon.png, icon-512.png, site.webmanifest  ← browser tab and phone home-screen icons
robots.txt, sitemap.xml  ← for search engines
.editorconfig, .gitattributes, .gitignore  ← editor and Git settings (from HTML5 Boilerplate)
projects/2019-1/         ← one folder per project
    model.glb            ← compressed 3D model (shown and downloadable)
    drawing.webp         ← drawing shown on the page
    drawing.pdf          ← drawing download
    card.webp            ← home-page picture: part top + bottom (800×400)
    card-400.webp        ← same picture, 400×200, for small or 1x screens
    og.jpg               ← 1200×628 picture used when the page is shared (LinkedIn, WhatsApp, Facebook, X)
    top.jpg              ← small picture for Previous/Next
templates/, data/, notes/, scripts/  ← what the pages are built from (see above)
```

## Viewing it on your computer

Pages open by double-clicking, but the 3D model only loads from a web server:

- **VS Code:** install "Live Server", right-click `index.html` → **Open with Live Server**.
- **Python:** run `python -m http.server` in this folder, then open http://localhost:8000

## Publishing on GitHub Pages

Push this folder to the `machinisthands/worldskillls` repository, then in GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**, choose the branch and the `/ (root)` folder. The `.nojekyll` file tells GitHub to serve the files as they are.

After it is live, add the site in [Google Search Console](https://search.google.com/search-console) and submit `https://machinisthands.github.io/worldskillls/sitemap.xml`. If you later use your own domain, change `SITE_URL` at the top of `scripts/build.py` and run the build again.

## Adding a new project (for example 2024, Test Project 1)

1. Make a folder `projects/2024-1/` with `drawing.pdf` and the drawing as `drawing.webp` (convert a JPG/PNG with any image tool, or `python -c "from PIL import Image; Image.open('drawing.jpg').save('drawing.webp', quality=82)"`).
2. Compress the 3D model into it:
   `npx @gltf-transform/cli draco "3D Model.gltf" projects/2024-1/model.glb`
3. Add one entry to `data/projects.json`:
   `{"dir": "2024-1", "year": 2024, "project": 1, "host": "Lyon, France", "pdfKB": 150, "glbKB": 200, "drawingW": 1500, "drawingH": 1060}`
   (`pdfKB`/`glbKB` are the file sizes shown on the download buttons; `drawingW`/`drawingH` are the drawing image's pixel size.)
4. Run `python scripts/build.py`.
5. Make the pictures `card.webp`, `card-400.webp`, `og.jpg` and `top.jpg` with `scripts/render_cards.py` (instructions at the top of that file).
